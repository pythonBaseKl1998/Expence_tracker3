Трекер затрат: Веб-приложение отслеживания личных затрат, где пользователи (например члены вашей семьи) могут добавлять свои расходы и доходы, просматривать статистику и управлять своим бюджетом. В БД будут храниться информация о каждом пользователе и их расходы и доходы.
«Приложение построено на фреймворке Flask.
На бэкенде используются: Flask 3.0, SQLAlchemy 2.0 как ORM, WTForms для валидации, Flask-Login для управления сессиями.
На фронтенде: Jinja2 для шаблонов, Chart.js для графиков, Bootstrap 5 для интерфейса и Flatpickr для выбора дат.
База данных — SQLite, но благодаря SQLAlchemy её легко заменить на PostgreSQL.
Для тестирования используется pytest.
Справа на слайде показана схема архитектуры: браузер отправляет HTTP-запросы, Flask обрабатывает их, SQLAlchemy работает с базой данных».
